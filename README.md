# 灵感星球（iOS）

仅包含 Lily / Leo 双角色智能体数字人页面。功能包括人物动态切换、文字对话、语音识别、Duix 口型驱动、
系统语音朗读、逐句高亮、复制、会话记录，以及加载/聆听/思考/朗读轮播动画。

- App 名称：灵感星球
- Bundle ID：`cn.cjym.inspireplanet`
- 最低系统：iOS 15

建议使用 `InspirePlanet.xcworkspace` 打开并运行；不使用 CocoaPods 时也可以直接打开
`InspirePlanet.xcodeproj`。Duix 官方 SDK 源码位于
`ThirdParty/Duix`，Lily 与 Leo 模型位于 `InspirePlanet/Resources/duix`。
